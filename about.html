About this project

This IBM project was built by Imaad with Krishna & Yashwanth.

IBM is something that has been part of all technical advancements and driven the evolution, every time, all throughout the world and even beyond. My attempt was to make it visual, which I built for this ICA Bobathon of 2026. My first IBM Hackathon of the many many more to come. Hope you like it, this is me trying to actually see the Impact, from a farther lens. This project is a static web application built using HTML5, CSS3, and vanilla JavaScript. It leverages globe.gl for 3D Earth and Moon rendering, along with D3.js and TopoJSON to handle map geometry and country projections. The geographic base comes from Natural Earth world data (via world-atlas), complemented by custom IBM-themed textures for visual identity. Responsive design was implemented for desktop, tablet, and mobile, featuring distinct hover-card and moon positioning rules for each breakpoint. An Apollo 11 moon point experience was integrated, with an IBM Apollo history link and synchronized moon fade effect when zooming on Earth. IBM bob provided assistance and decision support throughout the code development process.
